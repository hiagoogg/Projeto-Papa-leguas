# Projeto Papa-Léguas

Aplicação web para gerenciar as entregas de um petshop, substituindo o registro em papel por um sistema acessível pelo celular.

**Status:** em desenvolvimento (fase inicial)

## O que o sistema vai fazer
- Cadastro de pedidos
- Registro das informações de entrega
- Acesso pelo celular

## Tecnologias
Node.js, Express, React e Firebase.
